# 目标分模式（显式开启）

本模式追求作者指定的 ChatGPT 前文风相似度，不能把它叫作可读性目标或 AI 使用率。它可能增加篇幅、造成局部退化或引入意思偏差，因此不是默认流程。只在作者开启后加载本文；所有运行证据保存在论文副本目录，不写入 skill 或公开仓库。

## 覆盖表

以下条款来自作者对目标分模式的显式选择。仅在本次模式内覆盖；未列出的默认要求继续生效。规则卡本身及普通 `writing-anti-ai` 调用不变。

| 模式条款 | 覆盖的默认条款 | 本模式行为 |
|---|---|---|
| T1 输入与可用性 | SKILL「共同目标与前提」的无服务仍可继续、无编译只注明；「准备」的未给上限只报变化 | 必须有目标、批准上限、可用的分数拆解及相应篇幅验证工具；缺少任一项不开跑或停止目标追求。上传仍须授权。 |
| T2 全文习惯改写 | SKILL「共同目标与前提」「准备／段落任务」「并行改写」的只列障碍、后续轮只定点修；规则卡 Requirement、原则 2/4、共同操作 3–5 和 Check 中只为减少推断才展开、已清楚就保留的限制 | 可把没有已定位障碍的清楚段落纳入习惯改写。仍逐处找唯一稿内依据，分开标记「关系理清」与「偏好性展开」，后者不得记作可读性改善。不要求每句都改。 |
| T3 目标与选稿 | SKILL「停不停与选稿」中无具体任务就停、无可确认表达改善就停、文风只在相当候选间二选一；规则卡共同操作末段及 Check 的默认 loop 停手／次级选分说明 | 达标且护栏全过就停；未达标且护栏全过可继续全文习惯任务，最多四轮。合格候选以目标分为选择依据；可读性退化仍独立报告，不能用涨分冲抵。 |
| T4 必做盲读 | SKILL「停不停与选稿」的可做时盲读、「交付」的盲读未做可注明 | 每轮及最终交付版本必须有隐藏版本身份与分数的比较；盲读遗漏或意思偏差未解决不能报通过。 |
| T5 硬护栏 | SKILL「编译和打分」的集中度 null 可经定性核对采用风格优势、版面可暂放开 | 相邻轮和原稿两组集中度都必须有数值且 ≤0.5；null／缺字段为未通过，不能记作零。批准上限不能临时放宽来达标。 |
| T6 必报代价 | SKILL「交付」的一般摘要 | 结束时必须向作者展示本文末尾全部报告项，与分数并列；未完成项写原因、影响及证据，不能填零冒充已查。 |

T2 只授权改写方式偏好，不覆盖规则卡的命题、证据、术语、情态、必要披露及上下文要求。不补目的、因果或唯一解释不存在的所指；不按词率选词，不向子代理发送分数、目标、差值、计分词表、权重或集中度。主代理的编辑边界沿用 `skills/writing-anti-ai-loop/SKILL.md`「不要做」中「不在子代理之外自己逐句改写来追分」一项。

## T1 开跑前

1. 在 `LOG.md` 记录开启模式的作者来源、目标（有限数值，0–100）、批准上限及其适用范围（是否含摘要、参考文献、附录）、计数工具和编译命令。同时有词数与页数限制时，两者都须满足。没有已批准上限就先获取输入，不能自行设定；只有词数上限时也记录实际页数，不能把词数当页数。
2. 按默认准备建立 `orig/`、`work/`、章节任务与锁台账。固定词数口径：指定正文文件及环境，记录正文词数、排除内容、工具版本和命令，原稿／每轮／最终一律同口径。服务的 `words` 是评分样本词数，除非口径核实一致，不代替正文词数。编译基线，记录正文终页、参考文献起页、总页数、距批准上限余量；不能编译或无法验证批准上限时不开跑。编译产物放临时副本，保留可核查的日志与 PDF。
3. 仅向已获授权的服务请求，保存 JSON 和绑定的源文件 SHA256：

   ```bash
   python3 "$CS/skills/writing-anti-ai-loop/scripts/score.py" <out>/orig --main main.tex --target-style <目标> > <out>/score-orig.json
   ```

   `--target-style` 只是诊断参数，不会自动授权上传、派代理或证明护栏通过。退出码 3 表示目标诊断不可用，停止本模式；退出码 1 是输入或响应错误，也先停止并报告。旧服务仍可供默认流程评分，但缺拆解不得估算后开跑。不在客户端复制公式或模型参数。
4. 开跑前向作者报告 `style_breakdown` 的虚词扣分、措辞扣分、其他扣分（如封顶），当前分、`wording_cleared_style`、当前差值 `gap`、仅清措辞的增益上限 `wording_only_gain_ceiling` 及剩余差值 `gap_after_wording_clear`。当前分已达目标时不制造改写，走最终验收与代价报告；无改动的集中度记「不适用：相同哈希」，不可把 null 当作数值通过。

### 分数拆解的口径

服务返回 `style-breakdown-1`，按 `function_words_then_wording_then_cap` 顺序分配**整数分的扣分点数**：先虚词，再措辞，再其他封顶。三项加当前分等于 100。它复用服务现有 bounded 评分函数，未改公式；非线性模型的两项不是可独立相加的原始惩罚，换分配顺序会改变解释。

`wording_cleared_style` 是保持当前正文／虚词率不变，仅令措辞命中清零、保留其他封顶的反事实分数。称「措辞全清最多到几分」时必须带上这个条件；真实改写会同时改变词数和词率，不保证到达此值，也不是所有改写的上界。分数取整会掩盖小变化，不据此推断不存在收益。

## T2 每轮派发

沿用默认分章、全新子代理、首轮 anti-AI 检查、后续轮六原则、prompt 来源核查与锁要求。在原模板的「改前任务」后追加下段，并注明它覆盖模板中只列问题段落及只按读者任务修改的限制。把具体授权记录路径填入 `{mode_source}`，不给子代理本文分数拆解或报告数据。

```text
[来源：writing-anti-ai-loop 目标分模式 T2；作者授权 {mode_source}]
在分配章节的全部可编辑正文里做一遍写作习惯改写，不局限于已标出的段落：
- 名词串按已知修饰关系拆成从句或 of 短语，保留通用术语本体和动作方向。
- 已有目的用动词从句说明，不补论文没有的用途，也不重复标题充数。
- 指代写出已有依据的所指，不自行在多个可能对象中选一个。
- 范围用具体动词或从句交代，保留原来的量化、条件、例外与证据强度。
没有对应结构、展开生硬、依据不唯一或与锁／篇幅冲突时可以保留并说明。
对每处实际改动记录位置、稿内依据及类别「关系理清」或「偏好性展开」。
后一类允许意思已清楚但换成作者偏好的习惯写法，不能声称减少了理解障碍。
复核完整段落，防止重复句架、新的嵌套负担和意思偏差。
```

全部可编辑章节都要覆盖；受保护内容仍照默认排除和报告冲突。不把局部词数变成硬配额，不删事实给展开腾空间。

## T3–T5 验收、盲读与停止

1. 每轮按默认顺序审 diff、核保真、规则、锁来源、段落关系与编译版面。记录已发现的每处改写偏差，即使已回退也不能从代价台账消失。强度、范围、施事／对象、因果、事实词分别核对。每个偏差给稳定 ID、轮次、位置、改前／改后、依据、修复／回退和复核结果；同一偏差的反复检查不重复计数，修补新引入的独立偏差另计。
2. 每轮做盲读，固定比较单元为原稿段落或相邻段落组，拆段或合段不增加票数。至少覆盖本轮所有改动单元并提供必要上下文，逐对与 `orig/` 比较；另核与上一轮的退化。在 `blind/rN/` 保存 `pairs.json`（单元、范围、A/B 文本、哈希）、`key.json`（随机 A/B 身份映射与随机种子）和 `judgments.json`（逐对 A 更好／B 更好／相当／无法判断、理由与语义疑点）。让未参与改写的新读者／子代理只读匿名对照和必要上下文，不给 key、轮次、目标、分数或主代理结论。判断落盘后才解盲；隐藏文件名中的身份信息。不能由改写代理自称盲读。
3. 主代理核实盲读指出的意思偏差，确认的必须修复或回退；非偏差也要给稿内证据，不能静默丢弃。修补后对受影响单元重新随机化并由新读者盲读，旧判断保留以报告代价。按默认每轮至多两次补修，仍有护栏失败／未核项就停止目标追求，回到最近合格版本。不得把补修改名为新轮来绕过四轮上限。
4. 任何修改、回退、组合之后重新验收最终文本，不沿用旧哈希的判断、分数或 PDF。最终 `blind/final/` 比较 `orig/` 与实际交付稿，覆盖相对原稿的全部改动单元；未改内容列覆盖范围，不能把抽样结论写成全文结论。未改稿可记录相同哈希并做身份隐藏的基线对照，注明没有改写样本。
5. 护栏和盲读核对后评分，分别传 `--base <上一轮合格快照>` 和 `--base <out>/orig`，并带 `--target-style <目标>`，保存为 `score-rN-prev.json`、`score-rN-orig.json`。首轮两者同为 orig。两份当前分和源哈希应一致。两组 `gain_top3_share` 都须有数值且 ≤0.5；任何一组 >0.5、null、缺失或服务失效都停止目标追求。不能用人工解释替代数值护栏，也不要求子代理修改某几个词来过护栏。
6. 正文词数及实际页数每轮记录，余量按批准口径计算。超上限先把候选标为失败；本轮补修只可删确认为重复的表达或恢复合格改动，不删事实／限定、不改格式规避上限、不放宽上限。记超限值和处理过程；补修后仍超限就停止并回退。没有可验证的版面则未通过。
7. **达到目标且全部护栏通过就停止**；**护栏补修后仍不过或最多四轮用完也停止**。未达目标且护栏通过时可继续 T2，不要求另造理解障碍；不要求每轮涨分。已通过护栏的候选按分数选择，同分取更早版本；可读性结论与偏好分数分别报告。不得因某轮分高选入有未修语义偏差的文本。组合局部改动后必须重新完成全部验收及最终盲读／双基线集中度检查。

最近合格版本指经过本模式全部检查的候选；不存在时恢复原稿，注明原稿哪些规则／版面尚未通过，不能称完成版。回退版若等于先前快照，沿用它对应的上一轮基线并重验；若与 orig 相同，集中度记无改写不适用。返回状态区分「达标且通过」「未达标停止」「无合格改写」；每种状态都执行 T6。

### 盲读计数与可读性结论

解盲后报告最终改写版更好 B、原版更好 O、相当 T、无法判断 U 及总对数，注明覆盖范围与修前／修后版本。计数来自最终判断文件；另列每轮修前计数，不能把修前偏差随复评覆盖。U > 0 表示盲读未完成，不得验收为通过。

结论必须同时依据计数、覆盖范围和逐对理由，不能仅因 B>O 就宣布变好。改善与退化交错、没有一致方向时写「持平（本次盲读未见一致改善，不是等效证明）」；称「变好」或「变差」时说明哪些具体关系或阅读负担支持整体方向，列出相反证据及重要局部退化。将汇总结论、理由及所引用的 pair ID 写入 `blind/final/summary.md`。U>0 时结论为「未完成」，零对时为「未评」，不硬填持平。计数不能抵消事实错误；同一读者多对判断不等于独立读者实验，也不能由此宣称统计显著。此结论只用于报告，不是新增的分数优化目标或停止门槛。

## T6 给作者的必报模板

下面是必须在最终回复展示的报告，不得只留在 LOG 中。占位符填实测值；失败或未开跑时相应字段写「未评／不可用＋原因」，零仅用于确实检查为零。所有依据给可打开的路径和记录 ID；论文引文、数字和案例只留在论文的私有副本中。

```markdown
目标分模式结束：{达标且通过／未达标停止／无合格改写}；原因 {原因}。
交付 {work 路径及源哈希清单}；采用第 {轮次} 轮／组合／原稿，完成 {轮数}/4 轮。
文风 {原稿分} → {交付分}，目标 {目标}，仍差 {差值}。分数不代表可读性。

- 盲读：改写版更好 {B} 对／原版更好 {O} 对／相当 {T} 对，无法判断 {U} 对，覆盖 {范围及总对数}。
  可读性 {变好／持平／变差／未完成／未评}；依据 {summary.md、pair ID、逐对判断及局部退化}。
  修前各轮计数 {列表}；修后最终计数以上述 final 为准。
- 篇幅：正文 {原稿词数} → {最终词数}，变化 {100×(最终−原稿)/原稿}%（原稿为零则不可算）。
  口径／工具／命令 {记录}。正文终页 {页}，参考文献起页 {页}，总页数 {页}；批准上限 {范围、值、来源}。
  余量 {页或实测行数；无法测行数就报页，不伪造}；中途超限 {无／轮次、最大超限量、如何处理、复验结果}。
- 意思偏差：全程确认引入 {独立偏差数} 处（含已修／已回退）；修后残留 {数}，待核 {数}。
  {每一处 ID、类别（强度／范围／施事／事实词等）、位置、改前改后、怎么修、复核证据；不能只给总数。}
  原文自身问题 {另列，不计入改写引入}。
- 分数来源（固定顺序、整数扣分点数）：虚词 {原稿扣分} → {最终扣分}，贡献 {前−后}；
  措辞 {原稿扣分} → {最终扣分}，贡献 {前−后}；其他封顶 {前} → {后}，贡献 {前−后}。
  三项贡献之和 {值} = 总涨分 {值}。开跑前措辞清零分 {值}，清零后距目标 {值}（固定词率的反事实）。
  集中度：相对上一轮 {值}／相对原稿 {值}，各轮记录 {路径}。
  改写来源判断 {关系理清／偏好性展开／混合／无法归因}，依据 {改动台账、盲读理由、覆盖范围}。
  若涨分主要伴随名词短语展开而没有理清关系，直说这一点；不把虚词贡献自动等同于关系改善，
  也不宣称评分拆解能给每类结构改动做因果归因。
- 核查入口：盲读 {pairs.json、key.json、judgments.json、summary.md 的完整路径}；
  LOG {完整路径与小节}；偏差／改动台账 {路径及 ID}；分数 JSON {路径}；规则／保真／锁／编译证据 {路径}。
  未通过／未完成 {项目及影响}，不得以涨分替代这些结论。
```
